### Task 1 – Air Quality Forecasting

## Problem Statement

The objective of this project is to analyse historical air-quality measurements and build a machine-learning model to predict a future air-quality measurement.

## Project Sections

1. Data Understanding and Preprocessing
2. Exploratory Data Analysis
3. Feature Engineering
4. Machine Learning Prediction
5. Model Analysis
6. Findings and Conclusion

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

UCI Air Quality Dataset.

## Approach

The project includes:
- Data loading and inspection
- Missing-value handling
- Date and time processing
- Exploratory data analysis
- Time-based feature engineering
- Lag features
- Rolling average features
- Machine-learning prediction
- Model evaluation

## Results

Model results and visualizations are included in the Jupyter Notebook.

## Learnings

- Data preprocessing
- Exploratory data analysis
- Feature engineering
- Time-series forecasting concepts
- Machine-learning model evaluation

Handling missing values, creating time-based features, and maintaining the correct time order during forecasting were important challenges.

More advanced forecasting models and additional historical features could be explored to improve prediction performance.
